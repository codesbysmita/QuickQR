# QuickQR
QuickQR is a modern, minimal, and responsive QR Code Generator Web App.
It is built using HTML, CSS, and JavaScript.
It lets you instantly create and download QR codes with customizable colors and smooth dark/light themes.

✨ Features
🎨 Custom QR Colors – choose your favorite color before generating
🌗 Light & Dark Mode – switch seamlessly between both themes
💾 Auto Save – your last generated QR is automatically saved
⬇️ Download Option – instantly save your QR as an image
⚙️ Modern UI – glassy, full-page layout with smooth animations
📱 Responsive Design – works perfectly on all screen sizes

🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)
qrcode.js library

💡 How to Use
1. Enter the text or link you want to convert.
2. (Optional) Pick a custom color.
3. Click Generate QR.
4. Download or save it - that’s it!
